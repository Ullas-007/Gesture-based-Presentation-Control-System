# Gesture Presentation System

A Python-based presentation controller using hand gestures.

## Features

- Swipe left → Previous slide
- Swipe right → Next slide
- Fist → Pause/Resume
- Peace sign → Blank screen
- Keyboard fallback mode

## Technologies

- Python
- OpenCV
- MediaPipe
- PyAutoGUI
- NumPy

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
