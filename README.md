# Gesture-Based Presentation Control System 🖐️📑

An AI-powered, touchless presentation control system that tracks hand gestures via webcam using **MediaPipe** and **OpenCV**, triggering native keyboard inputs (`PyAutoGUI`) for real-time control over slide software (PowerPoint, Google Slides, Keynote, PDF viewers).

## ✨ Features & Gesture Map

| Gesture | Action | UI Indicator | Description |
| :--- | :--- | :--- | :--- |
| 👈 **Swipe Left** | Previous Slide | `<< PREV SLIDE` | Rapid horizontal movement of index fingertip leftwards |
| 👉 **Swipe Right** | Next Slide | `>> NEXT SLIDE` | Rapid horizontal movement of index fingertip rightwards |
| ✊ **Hold Fist** | Pause / Resume | `PAUSED` / `RESUMED` | Hold fist for ~8 frames to toggle gesture input |
| ✌️ **Peace Sign** | Blank Screen | `BLANK SCREEN` | Full-screen blackout overlay toggle |
| ⌨️ **Keyboard Fallback** | Fallback Control | Terminal CLI | Triggers CLI interactive mode if camera fails or is disabled |

## 🚀 Quick Start Guide

### 1. Prerequisites
Ensure Python 3.9+ is installed on your system.

### 2. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/Ullas-007/Gesture-based-Presentation-Control-System.git
cd Gesture-based-Presentation-Control-System
pip install -r requirements.txt
```

### 3. Run Application
Launch the gesture recognition engine:
```bash
python main.py
```

### 4. Interactive Shortcuts
* `SPACE` - Manual Pause Toggle
* `L` or `←` - Force Previous Slide
* `R` or `→` - Force Next Slide
* `Q` - Clean Quit & Resource Cleanup

## ⚡ Performance Optimizations

1. **Dynamic Scaling**: Swipe detection threshold dynamically adapts to hand distance (`hand_size` vector distance calculation).
2. **Resource Cleanup**: Explicit MediaPipe instance teardown (`hands.close()`) prevents memory leaks.
3. **Latency Optimization**: Lowers PyAutoGUI default delay to 50ms for snappy slide navigation.
4. **Resilient Failover**: Automatic fallback to CLI input after frame read loss threshold.
